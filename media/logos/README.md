# Dagster Logos

Please place the Dagster logo files here:

- **dagster-logo-dark.svg** - White/light logo for dark mode (the one you showed me)
- **dagster-logo-light.svg** - Colored logo for light mode

Both files should be SVG format and contain the full Dagster logo with the octopus icon and wordmark.

The extension will automatically use these embedded logos instead of loading from external URLs, ensuring they're always visible and theme-aware.
